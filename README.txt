TandaFácil v6 Bilingüe - Listo para Codemagic

INSTRUCCIONES CODEMAGIC (2 MIN):

1. Ve a https://codemagic.io/start -> Get started -> Login con Apple ID
2. Add application -> iOS app -> Manual -> Upload ZIP (sube este ZIP)
3. En Build settings:
   - Team ID: tu Team ID de Apple Developer (lo ves en developer.apple.com/account)
   - Bundle ID: com.tandafacil.app2026
   - Workflow: iOS Workflow
4. En Publishing -> App Store Connect -> Conecta tu Apple ID
5. Dale Start new build
6. Codemagic compila con Mac en la nube y lo sube a App Store Connect automáticamente
7. En 15 min aparece en App Store Connect > Tanda Facil > TestFlight > Builds
8. Ve a App Store Connect > 1.0 Preparar para envío > Selecciona Build > Añadir a revisión > Enviar

LISTO - Apple aprueba en 24h
